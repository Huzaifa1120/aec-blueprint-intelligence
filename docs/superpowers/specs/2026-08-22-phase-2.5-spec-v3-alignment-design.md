## 1. Purpose

Bring the codebase in line with Design Spec v3 before Phase 3 starts. The v3 revision changed things that touch existing code and added new obligations. Six work items from `Phases.md`:

1. Input Quality Gate (`degraded_vector` detection) + flattened-sample spike
2. Clustering migration: sklearn DBSCAN → deterministic distance-threshold union-find
3. Raster path re-proof via classical-CV template-matching spike
4. `source_quality` schema migration on COMPONENT / ROUTE / SPACE
5. Review-time instrumentation + `GET /projects/{id}/review-metrics`
6. Dependency hygiene: ultralytics quarantine, scikit-learn removal after DBSCAN exit

Nothing here re-opens Phase 1/2 results — every change must reproduce existing verified counts.

| Decision | Choice | Rationale |
|---|---|---|
| Scope | **Full Phase 2.5** | Sample PDF restored to `data/samples/` (2026-08-22, copied from Downloads; gitignored by design); baseline re-verified **41/41 pytest green, ruff clean** |

| Review-time target | **≤10 min/sheet provisional**, stored in config, per-tier logging from day one, revisit after first 5–10 real review sessions | User is the business stakeholder (closed internal deployment); even 10 min is 6–24× faster than manual takeoff (1–4 h/sheet); threshold is a regression alarm, not a marketing claim |

## 3. Architecture & batch structure

Branch: `feature/phase-2.5-implementation` → dev → main (`--no-ff`, existing convention).
Baseline to protect: **41 passed / 0 failed pytest; ruff clean** (verified 2026-08-22).

```
Batch A — Schema foundation
  └─ Alembic migration: source_quality on COMPONENT/ROUTE/SPACE
     backfill existing rows = 'layered_vector'
         │ enables ▼
Batch B — Vector-path hardening
  ├─ app/ingestion/quality_gate.py (new) + GET /drawings/{id}/quality
  │   + POST /drawings/{id}/request-reexport
  ├─ app/ingestion/router.py: classify_upload() scores layer richness (not binary)
  ├─ app/parsing/clustering.py (new): union-find distance-threshold clustering
  │   └─ app/ingestion/vector.py switched over after parity proof
  ├─ Flattened-twin spike: reproducible flattened fixture ⇒ gate flags degraded_vector
  └─ Regression: component counts identical DBSCAN vs union-find on sample
         │ independent code ▼ (but needs B's counts as ground truth)
Batch C — Raster re-proof spike (test-scoped; no production pipeline changes)
  ├─ app/raster/legend.py extended: glyph template extraction from legend region
  ├─ backend/tests/test_spike_raster_reproof.py: cv2.matchTemplate + NMS vs rendered sheet
  └─ Report artifact: per-type counts vs vector ground truth (±10% gate)
         │ enables ▼
Batch D — Instrumentation & hygiene
  ├─ Review-session logging tables + GET /projects/{id}/review-metrics
  ├─ app/raster/yolo_detection.py quarantined (default-off env flag)
  ├─ scikit-learn removed from pyproject.toml once zero imports remain
  └─ Docs updated: Memory.md, Phases.md status
```

**Ordering rationale:** Batch A first because the quality gate writes `source_quality` verdicts and review metrics filter by them. Batch B lands before Batch C runs its comparison so the spike uses migrated-pipeline counts as ground truth. Batch D last because metrics read the schema column and quarantine/cleanup are closure work.

## 4. Component details

### 4a. Input Quality Gate — `app/ingestion/quality_gate.py` (new)

- `score_layer_richness(pdf_path)` returns `{distinct_ocg_count, tagged_path_fraction, has_legend_text}` via pymupdf: `get_ocgs()`, per-path `layer` attribute from `get_drawings()` (≥1.24 `rect`/`items` API), text extraction presence check.
- Verdict enum: `layered_vector | degraded_vector | raster`.
- Config constants in `app/core/config.py`: `DEGRADED_MIN_OCGS = 3`, `DEGRADED_MAX_UNTAGGED_FRACTION = 0.9`.
- `classify_upload()` in `router.py`: binary vector/raster density check first (existing logic), then richness scoring on the vector branch only.
- Degraded verdict behavior:
  - Response carries the loop-back message ("this file has no layer data; re-export with layers included, or provide the native DWG/DXF").
  - `POST /drawings/{id}/request-reexport` records the re-export request (closed-deployment loop-back, spec §5.5).
  - If the pipeline proceeds anyway (external bid document), every downstream measurement from that file is stamped `source_quality = degraded_vector` and receives a lower base-confidence multiplier — config constant `DEGRADED_CONFIDENCE_MULTIPLIER = 0.8` (tunable; provisional until calibrated against real degraded files) — applied in the e2e pipeline at `_boq_line` as the item's `confidence_score`, visible in the review UI per spec §7.12.
- New endpoints: `GET /drawings/{id}/quality`, `POST /drawings/{id}/request-reexport`.
- Fail-closed rule: if scoring itself errors, verdict defaults to `degraded_vector` — never silently happy-path.

### 4b. Clustering migration — `app/parsing/clustering.py` (new), `app/ingestion/vector.py`

- Pure module: `UnionFind` class + `cluster_paths(paths, threshold_mm, scale_factor)` implementing spec §7.4 exactly: bbox distance ≤ threshold ⇒ union; groups returned deterministically (sorted output for test stability).
- Threshold derivation per sheet: smallest legend symbol's real-world bbox diagonal (from legend/schedule data available at parse time), converted to px via scale factor. Fallback config default when no legend-derived size exists, with logged warning.
- Spatial candidate pairs via grid bucketing — no R-tree dependency (YAGNI at current sheet sizes).
- No sklearn at runtime after migration.
- **Parity contract:** one test runs old DBSCAN and new union-find on the sample fixture and asserts identical component counts *before* the pipeline switch flips.

### 4c. Raster re-proof spike — `backend/tests/test_spike_raster_reproof.py` (test-scoped)

- Render sample page via existing `app/raster/renderer.py` (pixmap) converted to an ndarray; glyph template extraction implemented in new focused module `app/raster/template_match.py` (contour-cell segmentation + `cv2.matchTemplate` TM_CCOEFF_NORMED + NMS); count matches per symbol type.
- Compare against vector ground truth (component counts from Batch B pipeline on same fixture).
- Template→type labels come from a pymupdf spatial join of legend text to glyph cells — the sample's legend text is extractable vector text, so no OCR is required for per-type counting. Aggregate-count gate remains the documented fallback only if label mapping proves unreliable on this sheet.
- Gate: ≤±10% deviation **per symbol type**; full comparison table written to report artifact (`docs/superpowers/reviews/2026-08-22-raster-spike-report.md`, generated via explicit env-var run so test runs keep the tree clean). Isolated type breaches from rotated symbols are acceptable findings when ≤2 types breach; >2 breaches = spike failed = revisit before relying on raster path.
- OpenCV (`opencv-python-headless`, Apache-2.0) added as backend dependency. Detectron2 segmentation explicitly NOT built (Stage 2 scope). Ultralytics never imported.

### 4d. Schema migration — Alembic revision

- Add nullable column `source_quality` (`VARCHAR`, values `layered_vector | degraded_vector | raster`) to `COMPONENT`, `ROUTE`, `SPACE`. (`SCHEDULE_BLOCK` gets it when that table is created, Phase 3+.)
- Backfill all existing rows `'layered_vector'`.
- E2E write path (`app/e2e/router.py`) stamps the gate verdict onto every persisted row.

### 4e. Review-time instrumentation — `app/review/` (new)

- Tables: `REVIEW_SESSION` (sheet_label as string — `Sheet` rows are not yet persisted by the pipeline; FK to sheets lands with Phase 3+ persistence, project_id nullable FK) and `REVIEW_ACTION` (session_id, item_id, action, confidence_tier, timestamp) — minimal viable instrumentation.
- `GET /projects/{id}/review-metrics` returns: avg minutes/sheet overall, avg per confidence tier, count of sessions, provisional target, and whether average breaches target.
- Config constant `REVIEW_TIME_TARGET_MIN = 10.0` (provisional; revisit after first 5–10 real review sessions).
- Endpoint returns valid empty payload when no sessions exist yet.

### 4f. Hygiene

- `app/raster/yolo_detection.py` quarantined: module import gated behind explicit `ENABLE_LEGACY_YOLO=1` env flag (default off) + banner docstring stating AGPL rationale and spec v3 §7.7 decision; no other module imports it.
- `scikit-learn` removed from `pyproject.toml` once grep confirms zero remaining imports.
- Docs updated: Memory.md progress log + open items, Phases.md status flip.

## 5. Error handling

| Failure | Behavior |
|---|---|
| Richness scoring raises on malformed PDF | Fail closed → `degraded_vector`, warning logged, loop-back offered |
| No legend-derived clustering threshold derivable | Config fallback threshold + logged warning (never crash mid-parse) |
| Template extraction finds no legend region | Spike fails loudly with diagnostic; ±10% gate not waived |
| Metrics endpoint queried with no sessions | Valid empty response, not 404/500 |
| Migration on DB with rows in unexpected state | Backfill is idempotent; migration tested on empty and populated DB |

## 6. Testing & DoD gates

New tests (pytest, `backend/tests/`, existing style):

1. `test_phase2_5_quality_gate.py`
   - Unit: scoring on synthetic rich/flat/edge path sets.
   - Integration: real sample ⇒ `layered_vector`; **true flattened VECTOR twin of the real sample** (same shapes redrawn without OCG definitions or layer attributes — the print-to-PDF effect) ⇒ `degraded_vector` + loop-back message; rasterized twin (pages rasterized to images) ⇒ `raster` verdict via the binary router check.
   - Twins generated programmatically via pymupdf — deterministic, CI-safe. (Note: rasterize-and-rebuild alone yields a `raster`, not `degraded_vector` file — both twins are required to prove both branches.)
2. `test_phase2_5_clustering_migration.py`
   - Parity: DBSCAN vs union-find identical counts on sample fixture.
   - Determinism: two consecutive runs, byte-identical grouping.
   - Threshold derivation from smallest legend symbol.
3. `test_spike_raster_reproof.py` (prefixed so pytest collects it)
   - ±10%-per-type gate with template→label spatial join; comparison table artifact written only when `RASTER_SPIKE_REPORT` env var points at the docs path.
4. `test_phase2_5_review_metrics.py`
   - Session/action logging; endpoint math; empty-DB response.
5. Migration test: column exists, backfill correct, e2e stamps verdicts.

## 8. Risks & mitigations

| Risk | Mitigation |
|---|---|
| Flattened-twin fidelity (OS print-to-PDF varies by driver) | Generate fixture programmatically via pymupdf — deterministic, CI-safe |
| Legend glyph templates poor quality on sample | Spike reports honestly; ±10% gate decides; failure documented as finding, triggers technique review not silent pass |
| Rotated symbols breach tolerance for isolated types | Acceptable for ≤2 types (recorded in table); >2 breaches = spike failed = revisit before relying on raster path |
| Union-find parity breaks on edge clusters (DBSCAN border-point semantics differ) | Parity test runs BEFORE switch-over; discrepancies investigated and resolved explicitly, never papered over |
| sklearn removal breaks hidden import | Grep sweep + full suite re-run before removal commits |

## 9. Success criteria

Phase 2.5 closes when the DoD checklist in §6 is fully checked, merged `feature/phase-2.5-implementation` → dev → main, and `Memory.md` reflects the new state. Phase 3 (Mechanical/HVAC) may then start.
