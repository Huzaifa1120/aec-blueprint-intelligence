## 4. Unused Dependencies

### Issue: `react` listed as unused

**File:** `package.json` — `react` in `dependencies`

**Analysis:** This is likely a **false positive**. Next.js 16 App Router with React 19 auto-globalizes React — it is available in scope without an explicit import. The fallow dead-code analysis does not account for this Next.js feature.

**Recommendation:** 
- Do **not** remove `react` from dependencies — it is required by Next.js even if not directly imported in every file
- The "unused" flag is a known limitation of the fallow configuration for Next.js + React 19 projects

**Effort to fix:** Low (verify by checking if app builds/serves without removing react)
